# FastAPI Streaming Platform  
Learning & Portfolio Project

## Описание
Учебный backend-проект, реализованный на FastAPI. 
На данный момент реализованы методы CRUD, есть разделение на web/service/data-уровни, 
подключена PostgreSQL+Alembic, все обёрнуто в докер, есть интеграционный тест.

Следующим шагом планируется создание из него стриминговой / VOD-платформы.
Проект создаётся с целью обучения backend-архитектуре и DevOps-практикам, а также
как портфолио-проект, демонстрирующий системный подход к разработке.

Основной фокус — не на бизнес-логике, а на:
- архитектуре приложения
- масштабировании
- асинхронной обработке задач
- инфраструктуре и наблюдаемости

---

## Архитектура

Nginx
├── FastAPI #1
└── FastAPI #2

PostgreSQL
└── Read Replica

Redis
RabbitMQ

Проект строится как stateless backend с горизонтальным масштабированием.

---

## Назначение компонентов

- **Nginx**
  - Reverse proxy
  - Load balancing между инстансами FastAPI
  - Точка входа в систему

- **FastAPI**
  - REST API
  - Аутентификация и авторизация
  - Управление видео, пользователями и метаданными
  - Отдача ссылок на стриминг

- **PostgreSQL**
  - Основное хранилище данных
  - Реплика используется для read-нагрузки

- **Redis**
  - Кэширование
  - Хранение временных данных (sessions, rate-limit, прогресс задач)

- **RabbitMQ**
  - Очереди фоновых задач
  - Асинхронная обработка видео (кодирование, подготовка HLS)
