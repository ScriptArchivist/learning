Подключаемся к контейнеру БД:
docker exec -it learning_app-db-1 psql -U postgres -d app


Добавляем пользователя:
INSERT INTO users (username, email, hashed_password, is_active, storage_limit, used_storage) 
VALUES ('vadim', 'vadim@example.com', 'password_hash', true, 10737418240, 0);

Удаляем пользователя:
DELETE FROM users WHERE id = 1;

Проверяем что он есть:
SELECT * FROM users;


Шаг 1 — /upload/prepare. Что это: подготовка загрузки:
FILE="/home/vadim/Downloads/video5204062485010747752.mp4"
FILENAME=$(basename "$FILE")
FILESIZE=$(stat -c%s "$FILE")

curl -s -X POST "http://localhost:8000/api/v1/videos/upload/prepare" \
  -H "Content-Type: application/json" \
  -d "{\"title\":\"test video\",\"filename\":\"$FILENAME\",\"file_size\":$FILESIZE}" | jq


Шаг 2 — /upload/{id}/upload/direct. Что это: фактическая загрузка файла?
curl -s -X POST "http://localhost:8000/api/v1/videos/${VIDEO_ID}/upload/direct" \
  -F "file=@$FILE" | jq .


Шаг 3 — /upload/{id}/upload/complete. Что это: подтверждение завершения:
curl -s -X POST "http://localhost:8000/api/v1/videos/${VIDEO_ID}/upload/complete" \
  -H "Content-Type: application/json" \
  -d '{}' | jq .



Получаем список видео:
curl -s "http://localhost:8000/api/v1/videos/?owner_id=1" | jq


Получаем видео по ID:
curl http://localhost:8000/api/v1/videos/1 | jq


Обновляем видео:
curl -X PUT http://localhost:8000/api/v1/videos/1 \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Новое название",
    "description": "Обновлённое описание",
    "visibility": "public",
    "is_blocked": false
  }' | jq


Удаляем видео:
curl -X DELETE http://localhost:8000/api/v1/videos/1 | jq
