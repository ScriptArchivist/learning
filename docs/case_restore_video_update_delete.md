# Case: восстановление API для обновления и удаления видео

## Контекст

В рамках рефакторинга проекта и выделения отдельных сервисов из монолита FastAPI были обнаружены проблемы с пользовательским API.

После разделения сервисов функционал **обновления и удаления видео** перестал быть доступным через HTTP API.

При этом бизнес-логика операций уже существовала в сервисном слое.

## Обнаруженная проблема

В сервисном слое проекта присутствовали функции:

- `update_video(...)`
- `delete_video(...)`

в файле:


service/video_service.py


Однако HTTP-ручки, которые должны вызывать эти функции, отсутствовали в API-слое.

Из-за этого API не предоставлял возможность:

- изменять метаданные видео
- удалять видео

Хотя сама бизнес-логика была реализована и полностью работоспособна.

## Анализ

Было установлено, что в API-слое отсутствуют следующие endpoint'ы:


PATCH /api/v1/videos/{video_id}
DELETE /api/v1/videos/{video_id}


Отсутствие этих ручек означало, что:

- API не предоставлял полный CRUD функционал
- клиентские приложения не могли изменять видео
- клиентские приложения не могли удалять видео

## Решение

Было принято решение **восстановить только HTTP-ручки**, не изменяя существующую бизнес-логику.

Это позволило:

- не трогать сервисный слой
- не менять логику обработки видео
- не менять структуру БД
- минимизировать риск регрессий

## Какие файлы были изменены

Изменения были внесены только в API-слой.

### Изменённые файлы


web/video.py
web/video_api.py


### Что было добавлено

В оба файла были добавлены:


PATCH /videos/{video_id}
DELETE /videos/{video_id}


Эти ручки используют уже существующие функции сервиса:


service.video_service.update_video()
service.video_service.delete_video()


## Что не изменялось

Чтобы избежать влияния на остальную архитектуру, **не изменялись**:


service/video_service.py
db/models.py
migrations
worker
upload-service
storage-service
outbox/events/broker
DTO модели


Все изменения ограничены **только API-слоем**.

## Функциональность после исправления

После добавления endpoint'ов API снова поддерживает:

### Изменение видео

Пользователь может изменить:


title
description
visibility


Endpoint:


PATCH /api/v1/videos/{video_id}


### Удаление видео

Пользователь может удалить видео полностью.

Endpoint:


DELETE /api/v1/videos/{video_id}


При удалении выполняются операции:

- удаляется запись из таблицы `videos`
- удаляется оригинальный файл видео
- удаляются HLS-артефакты
- удаляются thumbnails
- удаляются связанные записи (`video_formats`, `processing_tasks`)

## Почему DELETE возвращает 204

Endpoint удаления возвращает:


204 No Content


Это стандартное REST-поведение для операций DELETE.

Означает:


операция успешно выполнена
ответное тело отсутствует


## Результат

После внесённых изменений API снова предоставляет полный CRUD интерфейс для работы с видео.

При этом:

- бизнес-логика не изменялась
- архитектура сервисов не нарушена
- изменения минимальны и изолированы
